GETTING STARTED · AZEROTH v16.0.0

Welcome to Azeroth Companion

A browser-based World of Warcraft planning companion. You can begin with manual profiles; connected Blizzard features are optional.

New in v15 · Sovereign Character Nexus

Open My Character to choose a local character, link saved Talent Forge drafts, review personal goals, and optionally request public Blizzard character and equipment data. All data sources are clearly labeled.

To move a build between iPhone and PC, export a Character Nexus JSON package and import it on the other device. Imported guest builds stay separate from your original saves. This is manual file portability, not automatic cloud synchronization.

New in v16 · The Living War Room and World Atlas

Open the Living War Room to see your selected local character, saved drafts and next personal exploration goals. Try Command Search 2.0 for in-browser search across regions, manually saved characters and existing studio links.

The Living World Atlas offers an illustrated, intentionally schematic map and curated zones. Its destination pins are not official coordinates or live player tracking. You can create manual missions linked to your own character, draft or Item Atlas record. Save Protection includes these v16 records.

1. Explore the companion

Use the navigation menu to open Characters, Build Architect, Progression, Collections, and Data & Backup. Start in the Overview to find shortcuts and release information.

2. Create and review a build

Open Talent Forge Reforged through the complete companion, load a Blizzard-returned specialization, and explore Class, Specialization and Hero talents. Use the original plus and minus controls to plan ranks. Optional Ascendant View, Path Navigator and Guided Progression help explore the tree without automatically spending points. Source-reported connections may not establish actual in-game prerequisites.

3. Save and protect your work

Save Talent Forge drafts through the existing planner and use its export controls to retain portable copies. Other manual records can be backed up through Data & Backup. Local browser data does not automatically synchronize between PC and iPhone.

4. Install for easier access

iPhone: open the site in Safari, select Share, then Add to Home Screen (wording depends on iOS version). Android and desktop: look for Install app in your supported browser menu. A home-screen or desktop installation still uses online access for Blizzard and other connected resources.

5. Check for updates

The main Overview now has a Check for Updates action that reads the published version manifest without resetting your saved data. If a new version is available, reload the site to receive it. Visit the release history for details.

Complete studio tutorials

For detailed explanations of major studios, platform-specific tips, and feature limitations, open the PC tutorial or the iPhone / mobile tutorial. The Player Handbook is searchable and works without connecting Battle.net.

Living Azeroth · v9.0 Cinematic Experience

The main website now opens with a cinematic welcome. Click Enter Azeroth Companion to open the original full application directly underneath, without changing saved plans, Battle.net verification or music. Select one of the five illustrated chambers for a studio shortcut. After entering, the welcome stays dismissed for that browser tab; use the Living Azeroth entry in the sidebar to reopen it whenever you want.

To go straight to the original companion, use Open application directly. The standalone visual entrance is still available.

Begin at Living Azeroth. Choose from five illustrated chambers: Sovereign Ascension, Talent Forge, the Living Armory, Adventure Journal, and the Azeroth Oracle. Each leads to a working existing studio with new visual interactions. Use Cinematic, Balanced or Performance to control optional atmosphere. On supported devices, reduced-motion settings suppress particle effects.

These visuals do not invent equipped items, talent allocations, raid completions or private account information. The original controls and documentation remain available, including on iPhone and desktop.

Sovereign Ascension · v8.0

Visit Sovereign Ascension for the new unified workspace. Select Review My Local Plans to explicitly inspect existing manual records, use Load Blizzard Public Data for official public character and equipped-item information, compare two stored Talent Forge drafts, create an actionable mission, and use the optional source-aware Assistant Evidence Review. Exporting/importing a v8 snapshot never overwrites existing saved plans.

Source labels matter: local goals are not confirmed inventory or achievements, Blizzard-reported public gear is not the complete bag or bank, and unreported data is unknown rather than zero. The older studios remain available.

Mission Architect — Guided Action Plans

Open the ZevRo | Azeroth Assistant with its floating avatar (lowered on desktop so the Connected control stays accessible). Scroll to Mission Architect, choose a goal and select Generate Action Plan. Each plan has four instructions and direct studio links. Copy or export the plan when useful. No login, Blizzard credentials or changes to your saved data are involved.

Floating assistant shortcut · v7.9.8

On PC, use the upper-right ZevRo | Azeroth Assistant avatar. On iPhone/mobile, tap its shortcut in the top website header. A compact panel opens without leaving your current studio; close with × or use Full Page for the complete assistant. Suggestions may reflect the visible studio, but no account data or saved plans are examined.

Meet ZevRo | Azeroth Assistant

For quick answers, open ZevRo | Azeroth Assistant, ask a question or choose one from the suggested questions. Topic filters provide guidance for Battle.net connections, talents, gear, Mythic+, raids, reputations and backups. The assistant uses reviewed, curated guidance rather than a live AI model and does not read your personal character records.

One-click Character Progress Report

Open Progression Intelligence, enter a public character, and select Build Character Progress Report. The companion retrieves Mythic+, raid and reputation data in sequence, then shows a status for each. You can copy a plain-text summary, export one JSON file or cancel outstanding work. Missing Blizzard responses are not proof of no gameplay history. The report does not automatically save personal data.

Connected character research

In Character Intelligence, enter a public WoW character and select a Mythic+, Raids or Reputations shortcut. The new Progression Intelligence page receives the same public character details; press Load to fetch data. You can return to comparisons or copy a shareable character research link. This never transfers a Battle.net token or changes your saved progress.

Developer testing requests

Players with access to real WoW characters can use the Developer Test Requests checklist. Untested items remain unverified, not failed; create and share a report voluntarily.

Need a reminder?

The Launch Edition panel on Overview can be collapsed and reopened any time. Use the Companion's built-in feature notes for specifics and verify in-game requirements separately.
