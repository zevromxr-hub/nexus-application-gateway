GETTING STARTED · v7.9.8

Welcome to Azeroth Companion

A browser-based World of Warcraft planning companion. You can begin with manual profiles; connected Blizzard features are optional.

1. Explore the companion

Use the navigation menu to open Characters, Build Architect, Progression, Collections, and Data & Backup. Start in the Overview to find shortcuts and release information.

2. Create and review a build

Open Talent Forge, load a Blizzard-returned specialization, and explore Class, Specialization and Hero talents. Use the original plus and minus controls to plan ranks. Optional Ascendant View, Path Navigator and Guided Progression help explore the tree without automatically spending points. Source-reported connections may not establish actual in-game prerequisites.

3. Save and protect your work

Save Talent Forge drafts through the existing planner and use its export controls to retain portable copies. Other manual records can be backed up through Data & Backup. Local browser data does not automatically synchronize between PC and iPhone.

4. Install for easier access

iPhone: open the site in Safari, select Share, then Add to Home Screen (wording depends on iOS version). Android and desktop: look for Install app in your supported browser menu. A home-screen or desktop installation still uses online access for Blizzard and other connected resources.

5. Check for updates

The main Overview now has a Check for Updates action that reads the published version manifest without resetting your saved data. If a new version is available, reload the site to receive it. Visit the release history for details.

Complete studio tutorials

For detailed explanations of major studios, platform-specific tips, and feature limitations, open the PC tutorial or the iPhone / mobile tutorial. The Player Handbook is searchable and works without connecting Battle.net.

Floating assistant shortcut · v7.9.8

On PC, use the upper-right ZevRo | Azeroth Assistant avatar. On iPhone/mobile, tap its shortcut in the top website header. A compact panel opens without leaving your current studio; close with × or use Full Page for the complete assistant. Suggestions may reflect the visible studio, but no account data or saved plans are examined.

Meet ZevRo | Azeroth Assistant

For quick answers, open ZevRo | Azeroth Assistant, ask a question or choose one from the suggested questions. Topic filters provide guidance for Battle.net connections, talents, gear, Mythic+, raids, reputations and backups. The assistant uses reviewed, curated guidance rather than a live AI model and does not read your personal character records.

One-click Character Progress Report

Open Progression Intelligence, enter a public character, and select Build Character Progress Report. The companion retrieves Mythic+, raid and reputation data in sequence, then shows a status for each. You can copy a plain-text summary, export one JSON file or cancel outstanding work. Missing Blizzard responses are not proof of no gameplay history. The report does not automatically save personal data.

Connected character research

In Character Intelligence, enter a public WoW character and select a Mythic+, Raids or Reputations shortcut. The new Progression Intelligence page receives the same public character details; press Load to fetch data. You can return to comparisons or copy a shareable character research link. This never transfers a Battle.net token or changes your saved progress.

Developer testing requests

Players with access to real WoW characters can use the Developer Test Requests checklist. Untested items remain unverified, not failed; create and share a report voluntarily.

Need a reminder?

The Launch Edition panel on Overview can be collapsed and reopened any time. Use the Companion's built-in feature notes for specifics and verify in-game requirements separately.
