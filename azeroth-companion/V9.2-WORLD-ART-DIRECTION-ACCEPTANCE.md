# NEXUS | AZEROTH v9.2 — WORLD ART DIRECTION (STAGING)

## Scope
Visual-only upgrade of the already-hosted Citadel art system. No new binary artwork, authentication, Cloudflare worker deployment, saved-data migrations, or gameplay source changes are required.

## Existing artwork mapped to studios
- Main application wallpaper and hero: `citadel-hero-hd-v9.1.1.webp` (true 1600x900 landscape).
- Talent Forge / saved builds: `talent-forge-v9.1.webp`.
- Living Armory / character profiles and gear: `living-armory-v9.1.webp`.
- Progression Intelligence / adventuring and objective journals: `adventure-journal-v9.1.webp`.
- Azeroth Assistant / guide: `azeroth-oracle-v9.1.webp`.
- Sovereign Ascension / command: `sovereign-throne-v9.1.webp`.
- Addon Nexus / creation and tools: existing Talent Forge art.
- The alternate Living Azeroth five gateways now use the same distinct illustrations (instead of two repeated original stock portraits).

## Implementation boundaries
- A shared `studio-art-direction-v9.2.css` stylesheet loaded after original styles on main and external pages.
- Original old assassin source stays available for rollback/older style references; this patch does **not** remove existing files or alter unrelated studios.
- CSS `:has(.section.active[data-section=...])` selects active main-app illustrations; no new JavaScript, localStorage, cookies or tokens.
- Five original 380px-wide portraits remain smaller overlays and narrow cards; the landscape image supports large backgrounds.
- The assistant mini embed keeps compact visual styling and does not load a full promotional hero.
