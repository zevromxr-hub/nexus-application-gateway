Important storage guidance

Browser-local work is normally isolated by website origin and browser profile. If you switch from a GitHub Pages URL to your custom domain, or between Safari and another browser, the old browser's local data does not automatically transfer. Export from the original location before clearing Safari data or changing devices.

For the full companion, Talent Forge and the separate Command Board, use their original export functions where offered. This safety bundle contains only supported whitelisted local planning data.
