Your device guide

Sovereign Character Nexus · v15.0

Begin at My Character. Select your manually saved character and access its linked Talent Forge drafts, quests, Armory research and build package exchange.

Public Blizzard source vs manual records

Public character profile and equipment are retrieved only after you enter the region, realm slug and character name and press Load. This does not prove account ownership or grant live inventory sync.

Forge handoff

Use Open Character's Forge to carry local character context to Reforged. The interface preselects only a uniquely matching official specialization; it never auto-spends points.

Portable build packages

Export your own linked manual builds with optional private notes. Imported packages are validated and placed on an isolated Guest Build Shelf until you choose to download a draft for the native Forge importer.

For proper backups use Save Protection. Device testing remains a separate optional checklist under the owner-approved release policy.

Living World Engine · v16.0

Begin in the Living War Room: select a saved local character, view personal planning totals and use the new local-only Command Search 2.0.

Illustrative World Atlas

Open the World Atlas to explore curated region lists via an artistic, not-to-scale map. No pin reveals exact in-game coordinates, live routes, ownership or unlock status.

Personal adventure operations

Create a manual objective for a curated zone and optionally link a saved local character, Talent Forge draft or Item Atlas ID. Marking a goal complete changes only the local plan, not game progress.

Connected studio navigation

Move among Character Nexus, Forge, Atlas, Armory and Oracle through real links. Save Protection exports the mission key; browser-local files are not automatically synchronized across devices.

Three things to know

Blizzard data vs. manual notes

Sections explicitly labeled Blizzard-reported use API information. Local goals, attempt logs, ownership labels and estimated gear values are not automatic game reads.

Protect your progress

Export supported local plans from Data & Backup / Sovereign Data Vault. A verified Battle.net session is separate from browser-local planning storage.

Account safety

Only connect through Blizzard's authorization page. Private authentication stays in the Cloudflare account portal; downloads and links should be checked before installation.

Using Sovereign Ascension

Open Sovereign Ascension. Choose Review My Local Plans to inspect saved browser records without modifying them, or Load Blizzard Public Data to request a character profile and equipment information. Imported v8 JSON snapshots open only as previews and never overwrite existing records.

Talent Forge Ascension

ZevRo | Azeroth Assistant · v7.9.7

Open ZevRo | Azeroth Assistant for instant guided answers. Type a companion question, choose from generated suggested questions, or filter the documented topic library. Each recognized answer explains a feature and links to its corresponding studio. The assistant is a curated knowledge retriever, not a live generative AI model: no questions are sent to Blizzard or an AI provider, it never reads your Battle.net session, and it refuses to guess when no supported answer is found. For live gameplay details use the official game and Blizzard-backed studios.

Character Progress Report · v7.9.6

In Progression Intelligence, enter a public Retail character and select Build Character Progress Report. The site retrieves Mythic+, raid and reputation results sequentially, displaying an individual status for each category. One unavailable category does not erase successful results. Choose Copy Summary for plain text or Export Combined JSON for a snapshot. Press Cancel to stop outstanding requests. No data is silently saved or automatically sent to Discord.

Connected Character Research · v7.9.5

Choose a public Retail character in Character Intelligence. Use the new Mythic+, Raids, or Reputations shortcuts to carry the same region, realm slug, and character name to Progression Intelligence. Use Compare This Character to return, or Copy Research Link to share public character details. The destination always requires you to press Load; this feature never sends your Battle.net token or copies saved plans. If a shared link has invalid fields, correct them manually.

Recommended first session

Start at Overview → explore Talent Forge or Item Codex → create a Character Target → record progress in Farming Operations → export your local data backup. Use the secure account portal only if you want to inspect Blizzard-supported character or collection data.

When things don't look right

If a button seems missing, open the device's full menu and refresh once. For data that hasn't loaded, verify the correct Battle.net region and try again later. For browser-local records that vanished, check whether you changed browser, device, private mode or cleared site storage; restore from a trusted export if you have one. If an addon link is unavailable, visit the provider's site directly and check its current listing.
