Three things to know

Blizzard data vs. manual notes

Sections explicitly labeled Blizzard-reported use API information. Local goals, attempt logs, ownership labels and estimated gear values are not automatic game reads.

Protect your progress

Export supported local plans from Data & Backup / Sovereign Data Vault. A verified Battle.net session is separate from browser-local planning storage.

Account safety

Only connect through Blizzard's authorization page. Private authentication stays in the Cloudflare account portal; downloads and links should be checked before installation.

Blizzard researchProgression Intelligence · v7.9.4Review official character Mythic+ profiles, raid encounters and reputations.+

How to use it

Enter a public Retail character name, region and realm slug. Select Mythic+, Raids or Reputations and load Blizzard-reported data. Mythic+ can optionally use a numeric season ID. Export a JSON research snapshot manually.

What to know

Connected Character Research · v7.9.5

Choose a public Retail character in Character Intelligence. Use the new Mythic+, Raids, or Reputations shortcuts to carry the same region, realm slug, and character name to Progression Intelligence. Use Compare This Character to return, or Copy Research Link to share public character details. The destination always requires you to press Load; this feature never sends your Battle.net token or copies saved plans. If a shared link has invalid fields, correct them manually.

Help the developer test new features

Developer request · v7.9.5: WoW players can help verify Mythic+, raids, reputations, equipment comparisons, Battle.net connections and saved progress. Tests are voluntary; untested features stay marked unverified. Open the Developer Test Requests checklist and generate a report to share manually. Never include passwords, tokens or account cookies.

Recommended first session

Start at Overview → explore Talent Forge or Item Codex → create a Character Target → record progress in Farming Operations → export your local data backup. Use the secure account portal only if you want to inspect Blizzard-supported character or collection data.

When things don't look right

If a button seems missing, open the device's full menu and refresh once. For data that hasn't loaded, verify the correct Battle.net region and try again later. For browser-local records that vanished, check whether you changed browser, device, private mode or cleared site storage; restore from a trusted export if you have one. If an addon link is unavailable, visit the provider's site directly and check its current listing.
