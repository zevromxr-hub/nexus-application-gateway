# NEXUS | AZEROTH COMPANION v9.3.0 — LUMINOUS GLASS

**Status: staging. A visual facelift, not a new data release.**

## Why this patch exists
Loot Hunter and other functional studio panels looked flat and dark despite the premium fantasy backgrounds. This patch adds depth, visual hierarchy and strong readability to existing working components without rebuilding their templates.

## Updated experiences
- Main companion: Loot Hunter, Live Armory/Warcraft Research, item research, Talent Forge, dashboards, metrics, progression, collections, player guide, saved draft and reference-list panels.
- Standalone Character Intelligence, Progression Intelligence, Sovereign Ascension, Addon Nexus and Azeroth Assistant.
- Citadel entrance shortcut/utility cards, preserved illustrated portal artwork and sidebar navigation.
- Text input, select and textareas, button hover/focus and metric value contrast.

## Safe-by-design
- Shared file: `azeroth-companion/studio-art-direction-v9.2.css` (new additive **v9.3 Luminous Glass** section). All eight existing pages now load it at `?v=930`. **No additional CSS/JavaScript requests.**
- Panel background opacity remains ~94–98%, intentionally opaque enough to read against animated or detailed fantasy artwork.
- Desktop blur is a subtle 8px, confined to key panels and only at 900px+. Mobile avoids backdrop blur for smooth scrolling.
- Reduced-motion removes decorative transitions. Performance mode also avoids extra background blur.
- No CSS changes to artwork scale/position in the ZevRo panorama. No replacement of original images.
- No new storage, API calls, authentication, worker changes, player data migrations, media or server changes. Existing class names, ids, HTML markup, save interfaces and module JavaScript remain.
- Explicit focus-visible outlines preserve keyboard access; form and button semantics, primary/warning/verified colors remain under the existing logic.
