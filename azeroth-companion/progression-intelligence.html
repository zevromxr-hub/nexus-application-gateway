Privacy, API limits & technical details

Only the requested region, realm and character name are sent to the public NEXUS Cloudflare gateway. API credentials remain Cloudflare secrets. This tool does not request your Battle.net OAuth cookie, read saved progress, update your game account, or store results automatically. Export is manual. A v7.9.4 Worker deployment is required for the new progression routes. The app handles absent API data without inventing completion or ownership.
