How to use the intelligence

Enter the exact region, realm slug and character name. Load character A by itself or include a second character for a side-by-side equipment comparison. Open an item's official research endpoint by its ID if you need more detail. Export only when you're ready to save a local snapshot.

Sources: Blizzard's existing public character and equipment endpoints via the NEXUS Cloudflare gateway. API results may lag behind gameplay, be restricted, or return incomplete records. No account sign-in, Blizzard token, or local saved companion data is accessed by this page. The export records the returned profile/gear snapshot only.
