## 2. Critical preservation rule
Do NOT replace Cloudflare's live Worker without first saving its CURRENT full source and making sure you can roll back to the existing deployed version. The GitHub v7.9.4 Worker was derived additively from the preserved repo v7.9.1 owner source. A full byte-for-byte comparison with any subsequently modified live Worker has NOT been done. The new source file is intended for owner review and deployment, not an automatic update.

Save your live code to a private backup file, then copy the full source of `worker-v7.9.4-single.js` in the Cloudflare editor. Do not paste secrets into JavaScript. Keep `BLIZZARD_CLIENT_ID`, `BLIZZARD_CLIENT_SECRET`, and `AZEROTH_SESSION_SECRET` in Cloudflare Worker Secrets. Review the full diff before deploying. Preserve a prior deployment in Cloudflare history.
